  Quick Start                                                                                                              
                                                                                                                           
  # 1. Install deps                                                                                                        
  curl -LsSf https://astral.sh/uv/install.sh | sh
  uv sync                                                                                                                  
                                                                                                                         
  # 2. Set API key                                                                                                         
  cp .env.example .env   # add ANTHROPIC_API_KEY                                                                         
                                                                                                                           
  # 3. Validate the idea with Claude                                                                                       
  python validate_idea.py                                                                                                  
  # → Saves full analysis to reports/idea_validation_report.md                                                             
                                                                                                                           
  # 4. Train (after getting data)
  python scripts/train.py                                                                                                  
                                                                                                                         
  Key Design Decisions                                                                                                     
   
  - Architecture: ConvNeXt-V2 + BiLSTM + Attention Fusion — best 2024-2025 results (0.97 AUC)                              
  - Dual targets: Predicts MD (dB/year) AND VFI (%/year) simultaneously                                                  
  - Clinical weighting: Fast progressors (MD < -1.0 dB/year) are up-weighted ×2                                            
  - Datasets: Start with GRAPE + UWHVF (both open access)                                                                  
  - Claude Opus 4.6 with adaptive thinking for deep idea analysis                                                          
                                                                                                                           
  The knowledge base has everything you need to start studying before touching any data.
